# 中文小说人性化

在生成完整章节草稿、产生对比重写或审查散文是否有模板化机器模式时读取本页。

## 1. 人性化目标

### 1.1 减少模板感

- 避免重复的句式结构
- 避免机械的节奏
- 避免空洞的表达

### 1.2 增加角色区分度

- 每个角色有独特的说话方式
- 每个角色有独特的行为模式
- 每个角色有独特的情绪表达

### 1.3 增加真实感

- 对话自然流畅
- 情绪真实可信
- 细节具体生动

## 2. 人性化规则

### 2.1 句式变化

避免重复的句式：

```markdown
# 不好的例子
他走进房间。他看到桌子。他坐下。他开始工作。

# 好的例子
他推开房间的门，目光扫过凌乱的桌面，径直走到椅子前坐下，开始了今天的工作。
```

### 2.2 节奏变化

避免机械的节奏：

```markdown
# 不好的例子
他感到紧张。他感到害怕。他感到愤怒。他感到悲伤。

# 好的例子
他的心跳加速，手心开始出汗。恐惧像一只无形的手，紧紧攥住了他的心脏。
```

### 2.3 对话自然

避免空洞的对话：

```markdown
# 不好的例子
"你好。"他说。
"你好。"她说。
"今天天气不错。"他说。
"是的。"她说。

# 好的例子
"你来了。"她抬起头，眼中闪过一丝惊讶。
"嗯，路上有点堵。"他拉开椅子坐下，"你看起来很累。"
"昨晚没睡好。"她揉了揉太阳穴，"案子还没结。"
```

## 3. 人性化流程

### 3.1 识别问题

1. 检查句式重复
2. 检查节奏机械
3. 检查对话空洞
4. 检查表达模板

### 3.2 应用修复

1. 变化句式结构
2. 调整节奏快慢
3. 增加对话细节
4. 丰富表达方式

### 3.3 验证效果

1. 检查是否自然
2. 检查是否流畅
3. 检查是否真实
4. 检查是否有角色区分

## 4. 人性化检查清单

### 4.1 句式检查

- [ ] 是否有重复的句式结构
- [ ] 是否有机械的节奏
- [ ] 是否有空洞的表达
- [ ] 是否有模板化的描写

### 4.2 对话检查

- [ ] 对话是否自然流畅
- [ ] 角色是否有区分度
- [ ] 情绪是否真实可信
- [ ] 细节是否具体生动

### 4.3 描写检查

- [ ] 环境描写是否具体
- [ ] 心理描写是否真实
- [ ] 动作描写是否生动
- [ ] 感官描写是否丰富

## 5. 保护规则

### 5.1 保护事实

- 不修改核心事实
- 不修改角色设定
- 不修改世界观
- 不修改剧情走向

### 5.2 保护风格

- 不改变作者意图
- 不改变叙事视角
- 不改变语言风格
- 不改变节奏基调

### 5.3 保护结构

- 不改变章节结构
- 不改变场景划分
- 不改变情节顺序
- 不改变结局方向
