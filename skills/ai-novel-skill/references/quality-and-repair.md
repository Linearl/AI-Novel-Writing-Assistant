# 质量与修复

在评估质量、重写散文、修复连续性或推荐重规划时读取本页。

## 1. 质量评估维度

### 1.1 结构质量

- 章节目标是否明确
- 节奏段是否合理
- 伏笔是否回收
- 章末牵引是否有效

### 1.2 文风质量

- 是否有模板感
- 是否有解释性旁白
- 角色对话是否有区分度
- 节奏是否机械均匀

### 1.3 一致性

- 事实是否与已有设定冲突
- 角色行为是否符合人设
- 世界规则是否一致
- 时间线是否合理

## 2. 质量债务管理

### 2.1 债务分类

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| `local_patch_plan` | 本地可修复 | 记录，后续修复 |
| `continue_with_warning` | 带警告继续 | 记录，允许继续 |
| `patchable_obligation_gap` | 可补的义务缺口 | 记录，后续补充 |
| `draft_obligation_unmet` | 草稿义务未满足 | 记录，后续修复 |
| `defer_and_continue` | 延后继续 | 记录，允许继续 |

### 2.2 债务记录

在 `production/quality-debt.md` 中记录：

```markdown
# 质量债务

## 未解决债务

| ID | 章节 | 类型 | 描述 | 优先级 |
|----|------|------|------|--------|
| debt-001 | 15 | local_patch_plan | 对话缺少冲突 | medium |

## 已解决债务

| ID | 章节 | 类型 | 描述 | 解决方式 |
|----|------|------|------|----------|
| debt-000 | 10 | continue_with_warning | 节奏稍慢 | 后续章节加快 |
```

## 3. 修复流程

### 3.1 升级顺序

1. **接受可用内容**
   - 内容可用，即使有小问题
   - 不要因为局部风格问题丢弃可用章节

2. **记录非阻塞性质量债务**
   - 问题不影响阅读
   - 记录后允许继续

3. **应用针对性补丁**
   - 问题是局部的
   - 只修复问题部分

4. **重写章节**
   - 本地修复无法满足合同
   - 保留原有优秀部分

5. **推荐重规划**
   - 章节职责本身不可能或错位
   - 需要调整卷或章节计划

### 3.2 修复原则

- 不要创建无限修复循环
- 不要因为小问题丢弃可用内容
- 局部问题不阻断全局链
- 优先降级定稿 + 质量债务

## 4. 全局审核

### 4.1 审核维度

- 结构完整性
- 角色一致性
- 世界规则一致性
- 时间线合理性
- 伏笔回收率
- 节奏合理性

### 4.2 审核报告

```markdown
# 审核报告
```

## 5. Auto-Director 质量门

### 5.1 规则

- 局部问题（`local_patch_plan`、`continue_with_warning` 等）→ 继续推进 + 记录质量债务
- 全局阻塞（`stop_for_replan`、`replan_required`、不可恢复的生成失败）→ 停全局链
- 不要把局部问题路由到全局阻塞

### 5.2 判定标准

| 情况 | 判定 | 处理 |
|------|------|------|
| 对话缺少冲突 | 局部问题 | 记录债务，继续 |
| 节奏稍慢 | 局部问题 | 记录债务，继续 |
| 事实严重冲突 | 全局阻塞 | 暂停，等待决策 |
| 生成失败（不可恢复） | 全局阻塞 | 暂停，等待决策 |
