# 写法资产

在提取写法特征、应用写法资产、创建氛围写作卡时读取本页。

## 1. 写法资产分类

### 1.1 写法特征

从参考作品提取的写法特征：

```markdown
# 写法特征

## 基本信息
- ID：technique-001
- 名称：都市爽文开篇
- 来源：《诡秘之主》
- 类型：开篇技巧

## 特征描述
- 快速建立主角
- 制造悬念
- 展示能力

## 应用场景
- 都市异能小说
- 玄幻小说
- 灵异小说

## 原文样本
> 陈建国站在雨中，看着手中的外卖，心中充满了疑惑。

## 使用规则
- 前3章必须使用
- 每章至少一个钩子
- 避免过度解释
```

### 1.2 氛围写作卡

场景氛围参考：

```markdown
# 氛围写作卡

## 基本信息
- ID：atmosphere-001
- 名称：雨夜灵异
- 类型：场景氛围

## 氛围要素
- 时间：深夜
- 天气：大雨
- 地点：空旷街道
- 光线：昏暗
- 声音：雨声、风声
- 气味：潮湿、泥土

## 情绪基调
- 紧张
- 神秘
- 不安

## 描写要点
- 环境描写简洁
- 主角感受为主
- 灵异元素暗示

## 示例段落
> 雨越下越大，陈建国加快了脚步。街道上空无一人，只有路灯在雨中摇曳。突然，他感觉有人在身后，但回头却什么都没有。
```

### 1.3 节奏模板

章节节奏参考：

```markdown
# 节奏模板

## 基本信息
- ID：rhythm-001
- 名称：爽文节奏
- 类型：节奏模板

## 节奏结构
- 开篇（10%）：快速进入
- 发展（60%）：冲突升级
- 高潮（20%）：爽点爆发
- 收尾（10%）：钩子牵引

## 节奏控制
- 每章至少一个爽点
- 高潮间隔3-5章
- 情绪低谷每卷1-2次

## 应用场景
- 都市爽文
- 玄幻爽文
- 系统流
```

## 2. 写法提取流程

### 2.1 从参考作品提取

1. 分析参考作品
2. 识别写法特征
3. 提取原文样本
4. 总结使用规则

### 2.2 从用户输入提取

1. 理解用户描述
2. 总结写法特征
3. 生成使用规则
4. 创建写法资产

### 2.3 从生成结果提取

1. 分析生成结果
2. 识别优秀写法
3. 提取可复用部分
4. 创建写法资产

## 3. 写法应用流程

### 3.1 在章节计划中应用

```markdown
# 章节计划

## 写法约束
- 使用技巧：technique-001（都市爽文开篇）
- 使用氛围：atmosphere-001（雨夜灵异）
- 使用节奏：rhythm-001（爽文节奏）

## 具体应用
- 开篇：快速进入场景
- 发展：冲突逐步升级
- 高潮：爽点爆发
- 收尾：留下钩子
```

### 3.2 在正文生成中应用

1. 读取写法约束
2. 应用写法特征
3. 保持风格一致

### 3.3 在审核中检查

1. 检查写法合规性
2. 检查风格一致性
3. 记录问题

## 4. 写法资产管理

### 4.1 目录结构

```text
writing-techniques/
├── techniques/
│   ├── technique-001.md
│   └── ...
├── atmospheres/
│   ├── atmosphere-001.md
│   └── ...
├── rhythms/
│   ├── rhythm-001.md
│   └── ...
└── index.md
```

### 4.2 资产状态

| 状态 | 含义 | 说明 |
|------|------|------|
| draft | 草稿 | 可编辑 |
| confirmed | 已确认 | 可应用 |
| archived | 已归档 | 只读 |

### 4.3 资产复用

- 跨书复用：从一本书提取，应用到另一本书
- 跨卷复用：从一卷提取，应用到另一卷
- 跨章复用：从一章提取，应用到另一章

## 5. 写法工具

### 5.1 提取脚本

```bash
# 从参考作品提取写法
python scripts/writing_extractor.py extract analyses/<小说名> --output writing-techniques/

# 从用户输入创建写法
python scripts/writing_extractor.py create --name "都市爽文开篇" --description "快速建立主角，制造悬念"

# 列出可用写法
python scripts/writing_extractor.py list
```

### 5.2 应用脚本

```bash
# 在章节计划中应用写法
python scripts/writing_extractor.py apply novels/<小说名> --chapter 1 --techniques technique-001,atmosphere-001

# 检查写法合规性
python scripts/writing_extractor.py check novels/<小说名> --chapter 1
```
