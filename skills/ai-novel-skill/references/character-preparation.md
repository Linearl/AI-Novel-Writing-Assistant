# 角色准备

在创建、拆分、迁移、读取或更新角色资产时读取本页。

## 1. 角色分层

### 1.1 角色名册（character-roster.md）

紧凑索引，包含所有角色：

```markdown
# 角色名册

## 核心角色
| ID | 名字 | 功能 | 状态 | 最后出场 |
|----|------|------|------|----------|
| protagonist | 主角 | 主角 | active | 第15章 |
| antagonist | 反派 | 反派 | active | 第15章 |

## 配角
| ID | 名字 | 功能 | 状态 | 最后出场 |
|----|------|------|------|----------|
| mentor | 导师 | 辅助 | active | 第10章 |
| friend | 朋友 | 辅助 | active | 第12章 |

## 龙套
| ID | 名字 | 功能 | 状态 | 最后出场 |
|----|------|------|------|----------|
| guard1 | 守卫 | 背景 | exited | 第5章 |
```

### 1.2 角色档案

每个核心角色一个文件，包含完整信息：

```markdown
# 主角档案

## 基本信息
- ID：protagonist
- 名字：主角
- 年龄：25
- 性别：男

## 身份与外貌
- 身份：外卖员
- 外貌：中等身材，普通长相
- 标志：总是穿着外卖服

## 性格与动机
- 性格：坚韧、机智、善良
- 核心欲望：变强，保护家人
- 行动循环：送外卖 → 遇到灵异事件 → 解决 → 获得成长

## 人际关系
- 与反派：敌对
- 与导师：师徒
- 与朋友：友情

## 成长弧线
- 起点：普通外卖员
- 转折：获得看见鬼的能力
- 高峰：战胜第一个强敌
- 当前状态：受伤恢复中

## 本章呈现
- 可见身份：外卖员
- 衣着：外卖服，有血迹
- 状态：左臂受伤
- 可用物件：手机、神秘玉佩
- 行为锚点：习惯性摸玉佩
```

## 2. 角色准备流程

### 2.1 盘点目标区段

1. 确定当前卷/章节范围
2. 识别需要出场的角色
3. 检查角色状态

### 2.2 生成阵容方案

1. 核心角色：主角、反派、关键配角
2. 功能角色：导师、朋友、对手
3. 背景角色：龙套、路人

### 2.3 生成关系网

1. 核心关系：主角-反派、主角-导师
2. 辅助关系：朋友、盟友
3. 冲突关系：对手、敌人

### 2.4 生成动态系统

1. 角色状态追踪
2. 关系变化追踪
3. 成长弧线追踪

## 3. 角色一致性

### 3.1 硬事实

- 身份、外貌、性格
- 能力、限制
- 已知信息

### 3.2 软事实

- 状态变化
- 关系变化
- 成长变化

### 3.3 一致性检查

```bash
python scripts/quality_checker.py check-characters novels/<小说名>
```

```markdown
| 资源 | 类型 | 获取章节 | 状态 |

```

### 4.2 资源变更

- 获取：记录获取章节和方式
- 丢失：记录丢失章节和原因
- 消耗：记录消耗章节和效果

## 5. 角色退场

### 5.1 退场状态机

```text
active → exited (正常退场)
active → dead (死亡)
active → frozen (冻结)
```

### 5.2 退场处理

- exited：角色离开故事，但可能回来
- dead：角色死亡，不可复活
- frozen：角色暂时离场，可能回来
