# 连续性台账

在引导连续性、创建上下文包、接受章节、更新台账、记录质量债务或中断后恢复时读取本页。

## 1. 台账分类

### 1.1 事实台账

记录已确认的事实：

```markdown
# 事实台账

## 已确认事实
| ID | 内容 | 章节 | 类型 | 状态 |
|----|------|------|------|------|
| fact-001 | 主角获得超能力 | 第3章 | completed | active |
| fact-002 | 主角打败小Boss | 第10章 | completed | active |
| fact-003 | 主角身世之谜 | 第1章 | revealed | active |
```

### 1.2 伏笔台账

记录伏笔埋设与回收：

```markdown
# 伏笔台账

## 已埋设伏笔
| ID | 内容 | 埋设章节 | 状态 | 相关事实 |
|----|------|----------|------|----------|
| payoff-001 | 主角身世之谜 | 第1章 | planted | fact-003 |
| payoff-002 | 反派真实身份 | 第5章 | planted | - |

## 已回收伏笔
| ID | 内容 | 埋设章节 | 回收章节 | 方式 |
|----|------|----------|----------|------|
| payoff-003 | 守护者秘密 | 第8章 | 第15章 | 揭示 |
```

### 1.3 资源台账

记录资源获取与使用：

```markdown
# 资源台账

## 已获取资源
| ID | 内容 | 类型 | 获取章节 | 状态 | 所有者 |
|----|------|------|----------|------|--------|
| resource-001 | 神秘玉佩 | 物品 | 第5章 | in_possession | protagonist |
| resource-002 | 超能力 | 能力 | 第3章 | active | protagonist |

## 已使用资源
| ID | 内容 | 使用章节 | 效果 | 剩余 |
|----|------|----------|------|------|
| resource-003 | 治疗药水 | 第12章 | 恢复体力 | 0 |
```

```markdown
| 章节 | 状态 | 变化 | 原因 |

```

## 2. 台账更新流程

### 2.1 章节验收后更新

1. 提取新事实
2. 更新伏笔状态
3. 更新资源状态
4. 更新角色状态

### 2.2 更新规则

- 只更新已确认的事实
- 不更新用户编辑的内容
- 不更新推测性内容
- 保持台账一致性

### 2.3 更新检查

```bash
# 检查台账一致性
python scripts/continuity_store.py validate-ledgers novels/<小说名>

# 重建台账索引
python scripts/continuity_store.py rebuild-ledgers novels/<小说名>
```

## 3. 台账使用

### 3.1 上下文装配

从台账中提取当前章需要的内容：

1. 相关事实
2. 活跃伏笔
3. 可用资源
4. 角色状态

### 3.2 质量检查

检查台账一致性：

1. 事实是否冲突
2. 伏笔是否回收
3. 资源是否合理
4. 角色是否一致

### 3.3 恢复支持

从台账中恢复状态：

1. 加载最后验收章节
2. 加载相关台账
3. 生成上下文包
4. 继续执行

## 4. 台账格式

### 4.1 Markdown 格式

用于人类可读：

```markdown
# 连续性台账

## 事实
| ID | 内容 | 章节 | 类型 | 状态 |
|----|------|------|------|------|

## 伏笔
| ID | 内容 | 埋设章节 | 状态 | 回收章节 |
|----|------|----------|------|----------|

## 资源
| ID | 内容 | 类型 | 获取章节 | 状态 | 所有者 |
|----|------|------|----------|------|--------|
```

### 4.2 YAML 格式

用于程序处理：

```yaml
facts:
  - id: fact-001
    text: "主角获得超能力"
    chapter_order: 3
    category: "completed"
    status: "active"

payoffs:
  - id: payoff-001
    text: "主角身世之谜"
    planted_chapter: 1
    status: "planted"

resources:
  - id: resource-001
    text: "神秘玉佩"
    type: "item"
    acquired_chapter: 5
    status: "in_possession"
    owner: "protagonist"
```
