# 开书种子

当用户说"我没有想法"、"帮我想一个"、"开书种子"时读取本页。

## 1. 种子生成流程

### 1.1 发散阶段

围绕以下维度发散：

1. **读者幻想**：读者想体验什么？
2. **核心杠杆**：什么能让故事持续推进？
3. **前三章兑现**：前三章必须完成什么？
4. **升级地图**：主角如何成长？
5. **追读承诺**：读者为什么继续读？

### 1.2 筛选阶段

从发散结果中筛选 5 条种子：

1. **强钩子**：开篇就有吸引力
2. **人物成长**：主角有成长空间
3. **设定奇观**：世界观有吸引力
4. **关系牵引**：角色关系有看点
5. **悬念追查**：有悬念驱动

### 1.3 输出格式

```markdown
# 开书种子

## 种子 1：强钩子
> 外卖员陈建国在送外卖时，突然看见路边站着一个浑身是血的女人。

## 种子 2：人物成长
> 普通高中生偶然获得系统，从班级倒数逆袭成全校第一。

## 种子 3：设定奇观
> 未来世界，人类可以进入虚拟游戏世界，但每次进入都有死亡风险。

## 种子 4：关系牵引
> 青梅竹马的两人，因为一场意外分别十年，再次相遇时已是对手。

## 种子 5：悬念追查
> 神探在调查一起密室杀人案时，发现受害者竟然是十年前的自己。
```

## 2. 种子选择

### 2.1 用户选择

- 选择一条种子
- 修改一条种子
- 混合多条种子
- 提供自己的想法

### 2.2 方向确认

用户选择后，生成 2 份新书简报预览：

1. 书名、一句话定位
2. 目标读者/回报
3. 主角路径
4. 核心冲突
5. 早期钩子
6. 推进循环
7. 结局方向

两份预览必须在卖点、冲突、主角路径、推进循环、调性或结局方向上有明显差异。

## 3. 种子设计原则

### 3.1 五种方向

| 方向 | 说明 | 示例 |
|------|------|------|
| 强钩子 | 开篇就有吸引力 | 外卖员看见鬼 |
| 人物成长 | 主角有成长空间 | 系统逆袭 |
| 设定奇观 | 世界观有吸引力 | 虚拟游戏世界 |
| 关系牵引 | 角色关系有看点 | 青梅竹马变对手 |
| 悬念追查 | 有悬念驱动 | 密室杀人案 |

### 3.2 质量门控

每条种子必须通过：

1. **可执行性**：能发展成长篇
2. **差异化**：与其他种子明显不同
3. **吸引力**：能抓住读者
4. **成长性**：有成长空间
5. **悬念性**：有持续吸引力

### 3.3 避免的问题

- 不要太具体（限制发展）
- 不要太模糊（无法执行）
- 不要太常见（缺乏新意）
- 不要太复杂（难以展开）
- 不要太黑暗（读者不喜欢）

## 4. 种子到简报

### 4.1 渐进确认

从种子到简报，需要确认：

1. 读者频道（男频/女频/大众）
2. 连载形态（免费/付费/完本）
3. 主要阅读回报（成长/爽感/悬疑/情感）
4. 目标字数
5. 叙事视角
6. 节奏与语言倾向

### 4.2 确认原则

- 每次只问 2-3 个
- 提供 2-4 个选项
- 推荐项放第一
- 解释影响

## 5. 示例

### 5.1 无想法开书

用户：我没有想法，帮我想一个。

系统：我为你准备了 5 条开书种子：

1. **强钩子**：外卖员陈建国在送外卖时，突然看见路边站着一个浑身是血的女人。
2. **人物成长**：普通高中生偶然获得系统，从班级倒数逆袭成全校第一。
3. **设定奇观**：未来世界，人类可以进入虚拟游戏世界，但每次进入都有死亡风险。
4. **关系牵引**：青梅竹马的两人，因为一场意外分别十年，再次相遇时已是对手。
5. **悬念追查**：神探在调查一起密室杀人案时，发现受害者竟然是十年前的自己。

请选择一条，修改一条，混合多条，或告诉我你的想法。

### 5.2 有想法开书

用户：我想写一个都市异能小说，主角是个外卖员，突然能看见鬼。

系统：我为你生成了 2 份新书简报预览：

**预览 1：都市灵异爽文**
- 书名：《外卖员的灵异日常》
- 一句话定位：外卖员获得看见鬼的能力，从底层逆袭成灵异高手
- 目标读者：男频，18-35岁
- 主要阅读回报：成长与反转
- 主角路径：普通外卖员 → 灵异高手
- 核心冲突：人性与超能力的平衡
- 推进循环：遇到灵异事件 → 调查真相 → 对抗 → 成长
- 结局方向：揭开身世之谜，成为守护者

**预览 2：都市悬疑灵异**
- 书名：《鬼眼外卖》
- 一句话定位：外卖员看见鬼后，卷入一系列离奇案件
- 目标读者：男频，18-35岁
- 主要阅读回报：悬疑与解谜
- 主角路径：普通外卖员 → 灵异侦探
- 核心冲突：真相与危险
- 推进循环：接到订单 → 发现灵异 → 调查案件 → 揭开真相
- 结局方向：揭开城市背后的黑暗秘密

请选择一份，修改一份，混合两份，或告诉我你的想法。
