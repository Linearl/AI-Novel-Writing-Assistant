# 热门题材趋势

在处理流行排名主题、热门题材、近期市场方向、榜单构成或追踪机会时读取本页。

## 1. 分析范围

### 1.1 平台选择

| 平台 | 特点 | 受众 |
|------|------|------|
| 起点中文网 | 男频为主 | 18-35岁男性 |
| 晋江文学城 | 女频为主 | 18-35岁女性 |
| 番茄小说 | 免费阅读 | 大众 |
| 七猫小说 | 免费阅读 | 大众 |

### 1.2 频道选择

| 频道 | 特点 | 代表题材 |
|------|------|----------|
| 男频 | 爽感、升级 | 玄幻、都市、科幻 |
| 女频 | 情感、关系 | 言情、宫斗、穿越 |
| 大众 | 通俗、娱乐 | 悬疑、历史、武侠 |

### 1.3 时间窗口

- 近期（1周）：当前热门
- 中期（1月）：趋势变化
- 长期（3月）：市场方向

## 2. 分析流程

### 2.1 确认范围

1. 确认平台
2. 确认频道
3. 确认时间窗口
4. 确认榜单数量

### 2.2 捕获榜单

1. 获取榜单数据
2. 记录快照时间
3. 保存原始数据

### 2.3 提取信号

1. 分析标题特征
2. 分析标签分布
3. 分析简介模式
4. 分析题材构成

### 2.4 生成机会卡

1. 识别市场空白
2. 发现新兴题材
3. 评估竞争程度
4. 给出建议

```markdown
- 题材：历史
```


## 5. 分析原则

### 5.1 数据来源

- 只使用公开榜单数据
- 不读取小说正文
- 不伪造结论

### 5.2 分析边界

- 只分析元数据
- 不推断整本书质量
- 不预测未来表现

### 5.3 建议边界

- 只给方向建议
- 不给具体设定
- 不保证成功
