# 世界圣经

在创建、修改或消费小说的世界规则、势力约束或故事阶段时读取本页。

## 1. 世界框架

### 1.1 基本设定

```markdown
# 世界框架

## 世界类型
- 现代都市
- 虚拟世界
- 历史架空
- 仙侠玄幻

## 时代背景
- 当代（2024年）
- 近未来（2030年）
- 远未来（2100年）
- 古代

## 地理范围
- 城市：东海市
- 区域：华东地区
- 国家：华夏国
- 世界：地球
```

### 1.2 规则系统

```markdown
# 规则系统

## 核心规则
- 灵异规则：鬼魂存在，但普通人看不见
- 能力规则：只有特定人能看见鬼
- 限制规则：能力使用有代价

## 能力体系
- 基础能力：看见鬼
- 进阶能力：与鬼交流
- 高级能力：控制鬼
- 终极能力：封印鬼

## 限制条件
- 体力限制：使用能力消耗体力
- 精神限制：过度使用会精神崩溃
- 道德限制：不能用能力做坏事
```

### 1.3 势力格局

```markdown
# 势力格局

## 主要势力
- 守护者：保护人类的组织
- 猎鬼人：专门猎杀恶鬼的组织
- 鬼魂：各种鬼魂势力
- 普通人：不知道灵异存在

## 势力关系
- 守护者 vs 猎鬼人：理念冲突
- 守护者 vs 鬼魂：敌对
- 猎鬼人 vs 鬼魂：敌对
- 普通人 vs 所有：无知

## 冲突焦点
- 能力者的身份暴露
- 鬼魂的生存权
- 人类的安全
```

## 2. 世界阶段

### 2.1 阶段划分

```markdown
# 故事阶段

## 第一阶段：觉醒（1-30章）
- 主角获得能力
- 学习控制能力
- 遇到第一个鬼
- 打败第一个鬼

## 第二阶段：成长（31-60章）
- 能力提升
- 遇到更强的鬼
- 加入守护者
- 打败小Boss

## 第三阶段：转折（61-90章）
- 发现真相
- 遭遇背叛
- 能力觉醒
- 打败中Boss

## 第四阶段：高潮（91-120章）
- 最终对决
- 揭开身世
- 能力极限
- 打败最终Boss

## 第五阶段：结局（121-150章）
- 收束伏笔
- 世界和平
- 主角成长
- 完美结局
```

### 2.2 阶段规则

```yaml
# world-state.yaml
current_phase: "成长"
phase_start_chapter: 31
phase_end_chapter: 60
phase_rules:
  - 能力可以提升
  - 可以遇到更强的鬼
  - 可以加入守护者
  - 可以打败小Boss
```

## 3. 世界规则约束

### 3.1 硬约束

- 能力使用有代价
- 鬼魂不能被消灭，只能被封印
- 能力者不能暴露身份
- 普通人不能知道灵异存在

### 3.2 软约束

- 能力提升需要时间
- 鬼魂有强弱之分
- 势力之间有平衡
- 故事有阶段划分

### 3.3 违规处理

- 违反硬约束：记录质量债务
- 违反软约束：允许但记录
- 严重违规：暂停并等待用户决策

## 4. 世界管理

### 4.1 世界状态文件

```yaml
# world-state.yaml
version: "1.0"
world:
  type: "现代都市"
  era: "当代"
  location: "东海市"

rules:
  core_rules:
    - "灵异规则"
    - "能力规则"
    - "限制规则"
  
  current_phase: "成长"
  phase_chapter_range: [31, 60]

factions:
  - name: "守护者"
    status: "ally"
  - name: "猎鬼人"
    status: "neutral"
  - name: "鬼魂"
    status: "enemy"
```
