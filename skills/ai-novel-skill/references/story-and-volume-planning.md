# 故事与卷级规划

在创建或修改定位、钩子包、故事引擎、世界规则、角色阵容、卷战略、节奏板或章节清单时读取本页。

## 1. 规划层级

### 1.1 故事引擎

故事引擎是整本书的推进动力：

```markdown
# 故事引擎

## 主角欲望
- 核心欲望：变强，保护家人
- 短期目标：解决当前灵异事件
- 长期目标：揭开身世之谜

## 核心冲突
- 外部冲突：与反派的对抗
- 内部冲突：人性与超能力的平衡
- 环境冲突：灵异世界的危险

## 推进循环
1. 遇到灵异事件
2. 调查真相
3. 与灵异力量对抗
4. 获得成长
5. 准备下一个事件

## 兑现承诺
- 前3章：展示能力，解决第一个小事件
- 前10章：打败第一个强敌，获得认可
- 前30章：揭开部分身世之谜
```

### 1.2 卷战略

卷战略决定如何分卷：

```markdown
# 卷战略

## 总体结构
- 总卷数：5卷
- 每卷章节数：20-30章
- 总字数：200万字

## 各卷定位
| 卷 | 定位 | 核心冲突 | 兑现承诺 |
|----|------|----------|----------|
| 第1卷 | 起步 | 第一个强敌 | 展示能力 |
| 第2卷 | 成长 | 势力冲突 | 揭开部分真相 |
| 第3卷 | 转折 | 背叛 | 重大转折 |
| 第4卷 | 高潮 | 最终对决 | 高潮战斗 |
| 第5卷 | 结局 | 收束 | 完结 |

## 节奏控制
- 第1卷：快速建立，抓住读者
- 第2卷：稳步推进，展开世界
- 第3卷：制造转折，增加张力
- 第4卷：高潮迭起，推向顶点
- 第5卷：收束伏笔，完美结局
```

### 1.3 卷骨架

卷骨架是每卷的详细结构：

```markdown
# 第1卷骨架

## 章节分布
- 第1-3章：开篇，建立主角
- 第4-10章：第一个事件
- 第11-15章：成长与挑战
- 第16-20章：第一个强敌
- 第21-25章：高潮与结局

## 关键节点
| 章节 | 事件 | 作用 |
|------|------|------|
| 第1章 | 获得能力 | 建立主角 |
| 第5章 | 第一次战斗 | 展示能力 |
| 第10章 | 打败小Boss | 成长证明 |
| 第15章 | 遇到强敌 | 制造张力 |
| 第20章 | 打败强敌 | 卷高潮 |
| 第25章 | 揭示真相 | 卷结局 |
```

### 1.4 节奏板

节奏板是每卷的情绪曲线：

```markdown
# 第1卷节奏板

## 情绪曲线
| 章节 | 张力 | 情绪 | 备注 |
|------|------|------|------|
| 1-3 | 低→中 | 好奇 | 建立世界 |
| 4-7 | 中 | 紧张 | 第一次冲突 |
| 8-10 | 中→高 | 兴奋 | 第一次胜利 |
| 11-13 | 高 | 压抑 | 遇到困难 |
| 14-17 | 高→低 | 低落 | 失败与反思 |
| 18-20 | 低→高 | 激昂 | 反击与胜利 |
| 21-25 | 高 | 满足 | 收束与揭示 |

## 节奏控制
- 高潮间隔：5-7章
- 情绪低谷：每卷1-2次
- 伏笔回收：每卷末
```

## 2. 规划流程

### 2.1 从故事引擎到卷战略

1. 确定主角欲望和核心冲突
2. 设计推进循环
3. 规划分卷结构
4. 确定各卷定位

### 2.2 从卷战略到卷骨架

1. 为每卷设计章节分布
2. 确定关键节点
3. 设计情绪曲线
4. 规划伏笔埋收

### 2.3 从卷骨架到章节清单

1. 为每章设计具体事件
2. 确定章末牵引
3. 设计章间承接
4. 规划资源使用

## 3. 规划原则

### 3.1 先锁定承诺

- 先确定读者能获得什么
- 再设计如何兑现承诺
- 最后填充细节

### 3.2 前紧后松

- 前几卷规划更详细
- 后续卷保持灵活性
- 允许根据实际情况调整

### 3.3 保护已写内容

- 已写章节不被修改
- 已确认的设置不被覆盖
- 只有用户明确要求才能修改
