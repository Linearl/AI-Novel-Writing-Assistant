## 1. 任务概述

### 1.1 需求来源

用户构建桌面便携版后发现：
1. LLM API Key 等敏感配置被打包进种子数据库
2. 本地小说项目数据被打包进种子数据库
3. 桌面端口配置与 Web 开发端口冲突

### 1.2 核心内容

1. 构建时自动清理种子数据库中的敏感数据（APIKey、Novel、AppSetting 等 137 张表）
2. 桌面端 external 模式默认端口改为 13000（与 Web 开发一致）
3. 桌面端 managed 模式默认端口改为 14250（13000 + 1250 偏移）

### 1.3 前置条件

- 无
