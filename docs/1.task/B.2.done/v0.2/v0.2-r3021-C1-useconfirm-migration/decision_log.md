# 决策日志 — REQ-3021 useConfirm 迁移

## 决策 1：分批策略

- **决策点**：26 个文件如何组织迁移
- **选择**：按模块分为 10 批，每批 1-6 个文件
- **理由**：模块内文件关联紧密，同批迁移可减少跨批次依赖冲突；单批完成后立即验证，降低回归风险
- **日期**：2026-07-17
- **决策者**：AI 分析

## 决策 2：同步到异步转换策略

- **决策点**：`window.confirm` 是同步阻塞的，改为异步后如何处理
- **选择**：调用方全部改为 `await` 或 `.then()` 处理
- **理由**：`useConfirm` 返回 Promise，没有同步替代方案。React 事件处理器原生支持 async，影响可控
- **日期**：2026-07-17
- **决策者**：AI 分析

## 决策 3：非组件内的 confirm 调用

- **决策点**：纯函数或工具函数中的 `window.confirm` 如何处理
- **选择**：通过参数传入 confirm 函数，或提取到调用方组件中
- **理由**：hooks 只能在 React 组件或自定义 hook 中使用，非组件代码需要通过依赖注入获取 confirm 实例
- **日期**：2026-07-17
- **决策者**：AI 分析
