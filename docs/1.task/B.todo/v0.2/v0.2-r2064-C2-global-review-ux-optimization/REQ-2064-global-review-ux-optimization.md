# REQ-2064: 全局审校用户体验优化

## 背景

全局审校功能基本可用，但用户体验需要优化：
1. 页面宽度利用率低，问题列表和筛选挤在一起
2. 批量修复进度显示不够清晰
3. 修复完成后卡片状态不更新，缺少AI复核入口

## EARS 验收

1. **WHEN** 用户打开全局审校页面，**THE SYSTEM SHALL** 显示三栏布局：左侧筛选面板、中间问题列表、右侧修复进度
2. **WHEN** 批量修复进行中，**THE SYSTEM SHALL** 显示"正在修复第X/Y章，包含问题 #G001 #G002 #G003"
3. **WHEN** 批量修复进行中，**THE SYSTEM SHALL** 按章节数计算进度百分比
4. **WHEN** 章节修复完成，**THE SYSTEM SHALL** 更新该章节关联的问题卡片状态为"已修复"
5. **WHEN** 问题状态为"已修复"，**THE SYSTEM SHALL** 显示"AI复核"按钮

## 非目标

- 不改变批量修复的后端逻辑
- 不新增 Prisma 字段
- 不修改任务中心集成

## 风险

- 低风险：三栏布局可能在小屏幕上需要响应式处理
