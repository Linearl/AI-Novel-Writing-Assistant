# 决策日志：全局审校用户体验优化

## D1: 布局方案

- 决策：CSS Grid 三栏，固定侧边栏 + 中间弹性
- 理由：与项目其他页面（如步骤6编辑页）保持一致

## D2: 进度计算基准

- 决策：按章节数计算，不按问题数
- 理由：一个章节可能包含多个问题，用户关心的是章节处理进度

## D3: AI复核触发方式

- 决策：用户手动点击"AI复核"按钮
- 理由：自动复核可能消耗过多 token，用户应有控制权
